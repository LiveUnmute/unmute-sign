## House style

Brutalist: hard rules, square corners, no shadows, no gradients, one accent
(`#006AFE`), oversized headlines. Type is deliberately large — earlier decks were
readable on a laptop and unreadable from the back of a room.

| Use | Face |
|---|---|
| Headlines | Archivo Black |
| Labels, kickers | Archivo Bold, tracked +2 |
| Body | Space Grotesk Medium |

Both are SIL Open Font License and are committed in `../fonts/` so the build is
reproducible. The `.pptx` substitutes Arial Black / Arial, because a reviewer's
machine will not have the originals and silent font fallback ruins a deck.
